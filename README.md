# Tigela Cheia Store

Ecommerce front-end inspirado no projeto original da Tigela Cheia, agora com:

- vitrine de produtos
- filtros por categoria
- carrinho lateral
- resumo de compra
- checkout via WhatsApp
- salvamento simples no navegador

## Como usar

Abra `index.html` no navegador ou rode `server.js` para servir em localhost.

## Servidor local

O projeto inclui um servidor simples em Node.js:

```bash
node server.js
```

Ele sobe em `http://127.0.0.1:4281`.

## Observacao

Este e um ecommerce front-end. Para pagamentos reais, precisamos conectar um backend ou gateway de pagamento.
